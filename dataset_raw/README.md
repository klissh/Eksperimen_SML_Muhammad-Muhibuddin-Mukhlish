## Dataset Description

<mcreference link="https://paperswithcode.com/dataset/kaggle-credit-card-fraud-dataset" index="5">5</mcreference>
- Contains transactions made by credit cards in September 2013 by European cardholders
- Dataset presents transactions that occurred in two days
- 492 frauds out of 284,807 transactions
- Highly unbalanced dataset - positive class (frauds) account for 0.172% of all transactions
- Feature 'Time' contains seconds elapsed between each transaction and the first transaction
- Feature 'Amount' is the transaction amount
- Feature 'Class' is the response variable (1 = fraud, 0 = normal)
